# 造假案例库（Corpus 2026-08）

> 案例驱动开发：检测器的每一次升级都由**官方认定的真实造假论文**反向驱动。
> 本文件记录 v0.6.0 验证用的 8 篇案例、来源、检测命中与漏检分析，
> 以及独立对照组实验（无 WB 图稿的方法学/综述论文，验证误报率）。

## 为什么需要案例库

纸面单元测试无法回答"检测器在真实造假论文上有没有用"。ORI（美国科研诚信办公室）、
Rice 大学官方调查、Pfizer 官方声明先后公开认定了大量撤稿论文，其中部分为开放获取
（PLoS 系列），可直接下载原始 PDF 回放。这些案例构成检测器的 **ground truth**：

- **命中**：检测器标记位置与官方认定位置一致 → 检测器有真实价值
- **漏检**：官方认定造假但检测器没抓到 → 驱动下一轮迭代（v0.4.0 → v0.5.0 → v0.6.0 即由此驱动）

## 独立对照组（v0.6.0 新增）

LaneReuse 的阈值是在上述 8 个造假案例上调出来的（即"训练集"上 100% 命中）——这本身
不构成无偏验证。为压制过拟合风险，新增**从未参与参数调优**的对照组：

| 对照论文 | 类型 | LaneReuse 命中 |
| --- | --- | --- |
| Assistance dogs for veterans with PTSD (2022, `10.1371/journal.pone.0274960`) | 系统综述/meta | ✅ 0 簇 |
| Adenosine for postoperative analgesia (2016, `10.1371/journal.pone.0173518`) | 系统综述/meta | ✅ 0 簇 |
| Prevalence of Sleepwalking (2016, `10.1371/journal.pone.0164769`) | 系统综述/meta | ✅ 0 簇 |

对照组选型理由：**无 WB 图稿**（综述/方法学论文只有森林图、流程图、汇总表格），
如果 LaneReuse 在它们上产生命中，只能是误报。实测 3/3 零误报。

> ⚠️ 诚实边界：对照组样本仅 3 篇，且均为无 WB 图稿类型；对"含 WB 但干净"的论文
> （如前文发现的 2023 年 3 篇"表面干净实则被像素验证确认为真实重复"的论文——那 3 篇
> 实际是 PubPeer 尚未标记的真造假，LaneReuse 超额完成）尚未建立严格干净的 WB 对照组。
> 误报率结论需更大样本量复核。

## 命中 vs 官方认定的对应关系

### Brand et al. 2013 — HER3 western-blot 伪造（ORI）

ORI 认定 Figure 6B/6C 与 Figure 7A 的 western-blot 面板被重复使用/伪造。
RegionReuse 命中（v0.5.0）：

```
page6_Im3 g6x8_3c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 精确重复)
page6_Im3 g6x8_4c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 精确重复)
```

两条 **hamming 距离 = 0**（像素级感知哈希完全一致）的跨图重复，位置恰在
ORI 认定的 6B/6C 与 7A 区域。

LaneReuse（v0.6.0）进一步把逐对命中聚为 15 簇，最大簇 6 条泳道 / 12 个证据对
（corr=0.98），全部集中在 page4_Im2（Fig6）：b0l7 ↔ b1l5/b2l7/b3l5/b4l9 的
跨带星形网络——同一条带被复制到 4 个目标泳道。

### Yin et al. 2012 — PDK-1 靶点论文图片重复（Pfizer）

Pfizer 官方声明认定 Figure 1 与 Figure 2 存在重复使用的图片。
RegionReuse 的 6×8 细网格命中（v0.5.0 修复）：

```
page2_Im1 g6x8_4c5 <-> page6_Im4 g6x8_5c7   d=2
```

LaneReuse 补充 2 簇（2 对）。

## 漏检案例与迭代历史

### Yin & Nassirpour 2013 — miR-221（v0.6.0 已修复 ✅）

Pfizer 认定的图片重复为**带级**重复（条带被复制粘贴到不同泳道），对齐位置与
6×8 网格不一致 → 固定网格切分无法把重复条带切成同一 tile。这就是 v0.5.0 的
漏检根因，也催生了 **LaneReuse**（泳道级比对）。

v0.6.0 实测命中：

```
Figure 6 blot (page6_Im10.jpg) 第 6 条带:
  b6l2 ↔ b6l5 ↔ b6l8   三连重复（corr=0.968）
  b6l3 ↔ b6l9          重复对（corr=0.974）
```

正是 Pfizer 声明认定的 "duplicated bands inside western blots"。

### v0.4.0 → v0.5.0 的升级驱动

| 问题 | 案例证据 | v0.5.0 修复 |
| --- | --- | --- |
| 内容占比阈值把浅色 blot 面板当空白丢弃 | Yin et al. 案例漏检 | 纹理方差过滤 `TEXTURE_MIN_STD=6.0` |
| 3×3 网格抓不到条带级跨图重复 | Yin 2012 PDK-1 漏检 | 多尺度网格 `(3,3)+(4,4)+(6,8)` |
| 6×8 引入大量跨图假命中 | Brand 案例误报 2→29 条 | 分档阈值（6×8 → hamming ≤3） |

### v0.5.0 → v0.6.0 的升级驱动

| 问题 | 案例证据 | v0.6.0 修复 |
| --- | --- | --- |
| 固定网格切不到带级重复 | miR-221 漏检 | 新增 **LaneReuse** 泳道级比对 |
| 逐对输出 62 条 finding 太吵 | ZMARF 案例 62 对 | **Union-Find 聚类**折叠为簇（62 对 → 13 簇） |
| 图表碎片被误当泳道 → 对照组误报 | 方法学论文 1-5 个假簇 | 高度门控 `LANE_MIN_H=100` + 熵门控 `LANE_MIN_ENTROPY=1.0` |

## 复现方式

```bash
# 案例 PDF 存放（文件名：DOI 斜杠替换为下划线）
ls cases/10.1371_journal.pone.0071518.pdf

# 单案例回放：LaneReuse
python - <<'PY'
from paperdetective.ingest import ingest_path
from paperdetective.detect.lane_reuse import detect_lane_reuse, cluster_lane_hits
figs = dict(ingest_path("cases/10.1371_journal.pone.0071518.pdf").images)
hits = detect_lane_reuse(figs)
for c in cluster_lane_hits(hits):
    print(c["n_members"], c["n_pairs"], c["best_corr"], c["figures"])
PY
```
