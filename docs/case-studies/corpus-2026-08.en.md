# Fraud Corpus (2026-08)

> Case-driven development: every detector upgrade is driven by **officially
> confirmed** real fraud cases. This file documents the 8-case verification
> matrix used for v0.5.0, their provenance, hits, and miss analysis.

## Why a corpus

Unit tests on synthetic images cannot answer the question "does the detector
actually work on real fabricated papers?" ORI (US Office of Research Integrity),
Rice University's official investigation, and Pfizer's official statements have
publicly confirmed numerous retracted papers — several of them open access
(PLoS series), so the original PDFs can be downloaded and replayed. These cases
form the detector's **ground truth**:

- **Hit**: detector flags the same location the officials did → the detector
  has real value.
- **Miss**: officials confirmed fabrication but the detector caught nothing →
  drives the next iteration (v0.4.0 → v0.5.0 was driven exactly this way).

## Hits vs. official findings

### Brand et al. 2013 — HER3 western-blot fabrication (ORI)

ORI found that western-blot panels in Figures 6B/6C and 7A were duplicated /
fabricated. All 8 RegionReuse hits concentrate in Figures 6/7/8, with the core
signal:

```
page6_Im3 g6x8_3c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 exact duplicate)
page6_Im3 g6x8_4c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 exact duplicate)
```

Two cross-figure duplicates with **hamming distance = 0** (pixel-level
perceptual-hash identity) sit exactly in the regions ORI flagged (6B/6C & 7A).
Whole-figure pHash cannot see panel-level reuse — that is why RegionReuse exists.

### Yin et al. 2012 — PDK-1 image duplication (Pfizer)

Pfizer's official statement found duplicated images between Figure 1 and
Figure 2. The 6×8 fine grid catches it:

```
page2_Im1 g6x8_4c5 <-> page6_Im4 g6x8_5c7   d=2
```

This is a cross-figure lane-level duplicate that v0.4.0 missed and the **6×8
multi-scale grid** newly catches.

## Miss analysis & iteration history

### Yin & Nassirpour 2013 — miR-221 (still MISS ⚠️)

The duplication Pfizer confirmed is **lane-level** (bands copied into different
lanes) and its alignment does not match the 6×8 grid → fixed grids cannot cut
the duplicated bands into the same tile. **Iteration direction**: lane detection
+ band hashing, or sliding-window alignment instead of fixed grids.

### What drove v0.4.0 → v0.5.0

| Problem | Case evidence | v0.5.0 fix |
| --- | --- | --- |
| Content-ratio gate dropped light blot panels as blank | Yin et al. cases missed | Texture-variance filter `TEXTURE_MIN_STD=6.0` |
| 3×3 grid cannot see lane-level cross-figure reuse | Yin 2012 PDK-1 missed | Multi-scale grids `(3,3)+(4,4)+(6,8)` |
| 6×8 explodes cross-figure false positives | Brand case 2 → 29 hits | Tiered thresholds (6×8 → hamming ≤ 3) |

## Reproduction

```bash
# Case PDFs (filename: DOI with "/" replaced by "_")
ls cases/10.1371_journal.pone.0071518.pdf

# Single-case replay
python - <<'PY'
from paperdetective.ingest import ingest_path
from paperdetective.detect.region_reuse import detect_panel_reuse
figs = dict(ingest_path("cases/10.1371_journal.pone.0071518.pdf").images)
for p in detect_panel_reuse(figs):
    print(p)
PY
```
