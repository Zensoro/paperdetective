# Fraud Corpus (2026-08)

> Case-driven development: every detector upgrade is driven by **officially
> confirmed** real fraud cases. This file documents the 8-case verification
> matrix used for v0.6.0, their provenance, hits, miss analysis, and the
> independent control-set experiment (method/meta-analysis papers without WB
> figures, validating the false-positive rate).

## Why a corpus

Unit tests on synthetic images cannot answer the question "does the detector
actually work on real fabricated papers?" ORI (US Office of Research Integrity),
Rice University's official investigation, and Pfizer's official statements have
publicly confirmed numerous retracted papers — several of them open access
(PLoS series), so the original PDFs can be downloaded and replayed. These cases
form the detector's **ground truth**:

- **Hit**: detector flags the same location the officials did → the detector
  has real value.
- **Miss**: officials confirmed fabrication but the detector caught nothing →
  drives the next iteration (v0.4.0 → v0.5.0 → v0.6.0 was driven exactly this way).

## Independent control set (new in v0.6.0)

LaneReuse thresholds were tuned on the 8 fraud cases above — 100% on the
"training set" is not unbiased validation. To bound overfitting risk, a control
set **never used in tuning** was added:

| Control paper | Type | LaneReuse hits |
| --- | --- | --- |
| Assistance dogs for veterans with PTSD (2022, `10.1371/journal.pone.0274960`) | systematic review / meta | ✅ 0 |
| Adenosine for postoperative analgesia (2016, `10.1371/journal.pone.0173518`) | systematic review / meta | ✅ 0 |
| Prevalence of Sleepwalking (2016, `10.1371/journal.pone.0164769`) | systematic review / meta | ✅ 0 |

Selection rationale: **no WB figures** (reviews/methods papers contain only
forest plots, flow charts, summary tables). Any LaneReuse hit there could only
be a false positive. Measured: 3/3 clean.

> ⚠️ Honest boundary: the control set is only 3 papers, all of the no-WB type.
> A strictly-clean *WB-containing* control remains to be built — the 2023
> "clean-looking" WB papers tested earlier turned out to be real duplication
> (59% identical pixels, not yet flagged on PubPeer), which LaneReuse caught.
> The FP-rate conclusion needs a larger sample to firm up.

## Hits vs. official findings

### Brand et al. 2013 — HER3 western-blot fabrication (ORI)

ORI found that western-blot panels in Figures 6B/6C and 7A were duplicated /
fabricated. RegionReuse hits (v0.5.0):

```
page6_Im3 g6x8_3c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 exact duplicate)
page6_Im3 g6x8_4c8 <-> page14_Im7 g6x8_5c8   d=0  (Fig6 ↔ Fig7 exact duplicate)
```

Two cross-figure duplicates with **hamming distance = 0** (pixel-level
perceptual-hash identity) sit exactly in the regions ORI flagged (6B/6C & 7A).

LaneReuse (v0.6.0) further folds pairwise hits into 15 clusters; the largest
cluster has 6 lanes / 12 evidence pairs (corr=0.98), all inside page4_Im2 (Fig6):
a cross-band star network b0l7 ↔ b1l5/b2l7/b3l5/b4l9 — one band copied to 4
destination lanes.

### Yin et al. 2012 — PDK-1 image duplication (Pfizer)

Pfizer's official statement found duplicated images between Figure 1 and
Figure 2. The 6×8 fine grid catches it (v0.5.0 fix):

```
page2_Im1 g6x8_4c5 <-> page6_Im4 g6x8_5c7   d=2
```

LaneReuse adds 2 clusters (2 pairs).

## Miss analysis & iteration history

### Yin & Nassirpour 2013 — miR-221 (FIXED in v0.6.0 ✅)

The duplication Pfizer confirmed is **lane-level** (bands copied into different
lanes) and its alignment does not match the 6×8 grid → fixed grids cannot cut
the duplicated bands into the same tile. That miss motivated **LaneReuse**
(lane-level pixel comparison).

Measured in v0.6.0:

```
Figure 6 blot (page6_Im10.jpg), band 6:
  b6l2 ↔ b6l5 ↔ b6l8   lane triple (corr=0.968)
  b6l3 ↔ b6l9          lane pair (corr=0.974)
```

Exactly the "duplicated bands inside western blots" Pfizer confirmed.

### What drove v0.4.0 → v0.5.0

| Problem | Case evidence | v0.5.0 fix |
| --- | --- | --- |
| Content-ratio gate dropped light blot panels as blank | Yin et al. cases missed | Texture-variance filter `TEXTURE_MIN_STD=6.0` |
| 3×3 grid cannot see lane-level cross-figure reuse | Yin 2012 PDK-1 missed | Multi-scale grids `(3,3)+(4,4)+(6,8)` |
| 6×8 explodes cross-figure false positives | Brand case 2 → 29 hits | Tiered thresholds (6×8 → hamming ≤ 3) |

### What drove v0.5.0 → v0.6.0

| Problem | Case evidence | v0.6.0 fix |
| --- | --- | --- |
| Fixed grids cannot cut band-level duplication | miR-221 missed | New **LaneReuse** lane-level comparison |
| 62 pairwise findings drown the report | ZMARF case 62 pairs | **Union-Find clustering** folds them (62 → 13 clusters) |
| Chart fragments misread as lanes → control-set FPs | method papers 1-5 false clusters | Height gate `LANE_MIN_H=100` + entropy gate `LANE_MIN_ENTROPY=1.0` |

## Reproduction

```bash
# Case PDFs (filename: DOI with "/" replaced by "_")
ls cases/10.1371_journal.pone.0071518.pdf

# Single-case replay: LaneReuse
python - <<'PY'
from paperdetective.ingest import ingest_path
from paperdetective.detect.lane_reuse import detect_lane_reuse, cluster_lane_hits
figs = dict(ingest_path("cases/10.1371_journal.pone.0071518.pdf").images)
hits = detect_lane_reuse(figs)
for c in cluster_lane_hits(hits):
    print(c["n_members"], c["n_pairs"], c["best_corr"], c["figures"])
PY
```
